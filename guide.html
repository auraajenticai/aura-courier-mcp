  2. ধাপ ২ WooCommerce স্টোরের জন্য: ১-ক্লিকে আমাদের হালকা ব্রিজ প্লাগইনটি (aura-courier-woocommerce-bridge.php) ডাউনলোড করে WordPress-এ আপলোড করুন।
  3. ধাপ ৩ Shopify বা কাস্টম স্টোরের জন্য: ১-লাইনের <script src="https://courier.auraajenticai.cloud/sdk/aura-courier-widget.js"></script> আপনার অ্যাডমিন পেজে যুক্ত করুন অথবা Webhook কানেক্ট করুন।
  4. ধাপ ৪ এবার আপনার স্টোরের যেকোনো অর্ডারে ঢুকলেই ডানপাশে Aura Courier MCP বক্স দেখতে পাবেন—যেখানে কাস্টমারের রিয়েল-টাইম ফ্রড রিপোর্ট ও ১-ক্লিক কুরিয়ার বুকিং বাটন থাকবে!
  1. Step 1 Open Aura Client Portal (#view-courier) and save your Steadfast, Pathao, RedX, or Paperfly API keys once into the AES-256 Zero-Knowledge Vault.
  2. Step 2 For WooCommerce: Install the lightweight 1-file bridge plugin or connect your WooCommerce REST API keys.
  3. Step 3 For Shopify / Custom / Supabase: Connect via OAuth/Webhook or drop the 1-line Universal Admin SDK script into your order detail page.
  4. Step 4 Open any order in your store admin to see the live Customer Fraud Risk Score and dispatch to any of the 4 couriers with 1 click!
