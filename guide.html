⚡ ১. ৬০-সেকেন্ড রিমোট কুইকস্টার্ট 1. 60-Second Remote Quickstart

Aura Courier MCP সম্পূর্ণ ডুয়াল-ট্রান্সপোর্ট আর্কিটেকচার সমর্থন করে—অফিসিয়াল Server-Sent Events (SSE) এবং Streamable HTTP। কোনো লোকাল নোড প্রসেস বা ইনস্টলেশন ছাড়াই সরাসরি লাইভ সার্ভারের সাথে সংযুক্ত হতে পারেন: Aura Courier MCP natively supports dual transports: Server-Sent Events (SSE) and Streamable HTTP. Connect directly to the production cloud endpoint without local Node.js binaries:

Production MCP Endpoints 
# 1. Official SSE Transport (Claude Desktop / Cursor / Smithery)
https://courier.auraajenticai.cloud/sse?token=YOUR_API_KEY

# 2. Streamable HTTP Transport (LibreChat / Custom Gateways)
https://courier.auraajenticai.cloud/mcp?token=YOUR_API_KEY
প্রোটোকল নোট:Protocol Note: আমাদের সার্ভার স্বয়ংক্রিয়ভাবে Accept হেডার নরমালাইজ করে। যেকোনো AI এজেন্ট (Cursor, Glama, LibreChat) Accept: application/json পাঠালেও সার্ভার কখনোই 406 Error দেবে না। Our gateway automatically normalizes the Accept header. AI clients sending Accept: application/json will never receive HTTP 406 Not Acceptable.

🔐 ৩. অথেন্টিকেশন ও ক্রিপ্টোগ্রাফিক ভল্ট 3. Authentication & Vault Isolation

Aura Courier MCP সম্পূর্ণ Zero-Knowledge Multi-Tenant Vault নীতিতে পরিচালিত হয়। প্রতিটি মার্চেন্টের কুরিয়ার ক্রেডেনশিয়াল (Steadfast API Key, Pathao Client Secret, RedX Token) AES-256 এনক্রিপশনে তাদের নিজস্ব টেন্যান্টে সীমাবদ্ধ থাকে। Aura Courier MCP operates under a strict Zero-Knowledge Multi-Tenant Vault policy. Each merchant's carrier credentials are isolated under AES-256 cryptographic vaults.

অথেন্টিকেশন মেথডAuth Method ব্যবহারের ক্ষেত্রUsage অনুমতি ও এক্সেসPermissions
Authorization: Bearer <KEY> HTTP Header পূর্ণ Read ও Write পারমিশন। ১২টি টুলের অ্যাক্সেস।
?token=<KEY> URL Query Parameter রিমোট AI এজেন্ট (Cursor, Glama, Zapier) যেখানে কাস্টম হেডার দেওয়া যায় না।
x-steadfast-api-key BYOK Request Headers Bring Your Own Key মোড: সরাসরি গ্রাহকের কুরিয়ার অ্যাকাউন্ট ব্যবহার করে পার্সেল বুকিং।

❌ cancel_parcel LIVE CANCEL

সরাসরি আপস্ট্রিম কুরিয়ার সার্ভারে পার্সেল ক্যানসেল করার অথেনটিক ইঞ্জিন। পাঠাও, রেডএক্স এবং পেপারফ্লাইয়ের ক্ষেত্রে এমসিপি কল করলেই স্বয়ংক্রিয়ভাবে মূল কুরিয়ার সিস্টেমে পার্সেল ক্যানসেল হয়ে যায়। স্টিডফাস্টের ক্ষেত্রে স্ট্যাটাস যাচাই করে মার্চেন্ট ডিপ-লিংক প্রদান করে। Authentic upstream courier parcel cancellation engine. Automatically triggers real REST cancellation for Pathao, RedX, and Paperfly, and provides 1-click status validation for Steadfast.

Parameters

Field Type Required Description
courier string Required steadfast | pathao | redx | paperfly
consignment_id string Required Tracking code or consignment ID to cancel
reason string Optional Reason for cancellation (e.g. "Customer changed mind")

🛡️ ৬. প্রাইভেসি, অডিট লগ ও PII মাস্কিং 6. Privacy, Audit Logs & PII Masking

আন্তর্জাতিক ডেটা সুরক্ষা আইন অনুযায়ী পাবলিক ট্র্যাকিং পেজে গ্রাহকের ফোন নাম্বার সম্পূর্ণ মাস্কড (017****1234) থাকে এবং ঠিকানা জেলা পর্যায়ে সীমাবদ্ধ রাখা হয়। কোনো আনঅথেন্টিকেটেড রিকোয়েস্টে গ্রাহকের পূর্ণ নাম বা পূর্ণ ঠিকানা ডিসক্লোজ করা হয় না। In compliance with global data privacy standards, public tracking responses automatically mask recipient phone numbers (017****1234) and redact street addresses to district level for unauthenticated callers.
