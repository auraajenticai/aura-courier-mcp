// WHAT IT DOES

One interface, every courier

প্রতিটা courier আলাদা API — Aura Courier MCP সবগুলোকে একই সহজ toolset-এ এনে দেয়। আপনার AI-কে বলুন, বাকিটা ও করবে।

create_parcel

যেকোনো courier-এ ডেলিভারি বুক করুন (Steadfast, Pathao, RedX, Paperfly) — consignment ID + tracking code ফেরত।

track_parcel

consignment / invoice / tracking code দিয়ে রিয়েল-টাইম ডেলিভারি স্ট্যাটাস ও টাইমলাইন ট্র্যাকিং।

get_balance

courier মার্চেন্ট একাউন্টের ব্যালেন্স ও পেআউট স্ট্যাটাস (BDT)।

check_fraud_risk

পার্সেল পাঠানোর আগেই গ্রাহকের ফোন নম্বর বিশ্লেষণ করে ডেলিভারি সাকসেস রেট ও রিটার্ন রিস্ক প্রেডিক্ট করুন।

list_couriers

কোন কোন courier যুক্ত ও কোনটির ক্রেডেনশিয়াল কনফিগার করা আছে তা যাচাই করুন।
